# Module One: Introduction to Windows PowerShell

## Overview

This module provides a foundational introduction to **Windows PowerShell** and its role in system administration and automation. By the end of this module, learners will understand the core concepts of PowerShell and be able to perform basic operations confidently.

## Learning Objectives

In this module, you will learn to:

- Understand the PowerShell architecture and its role in automation
- Install and configure PowerShell on:
  - Windows
  - Linux
- Explore PowerShell environments:
  - PowerShell Console
  - Integrated Scripting Environment (ISE)
- Understand core PowerShell concepts:
  - Cmdlets
  - Objects
  - The pipeline
- Learn about execution policies and security considerations
- Familiarize yourself with basic PowerShell syntax and commonly used commands

## Prerequisites

- Basic understanding of operating systems (Windows or Linux)
- No prior scripting or PowerShell experience is required

## Module Structure

This module will include:

- Concept explanations
- Command examples
- Hands-on exercises (where applicable)

## Next Steps

After completing this module, you will be ready to move on to **Module Two**, where more advanced PowerShell concepts and scripting techniques will be introduced.
